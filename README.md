# CIREL_Salvage_HRQoL
This repository contains the analysis notebooks and lightweight helper code used for our study:

**“Early disease control after salvage irinotecan TACE is associated with preservation of emotional functioning: patient-reported outcomes from the CIREL registry”** 

## What is in this repository

- `notebook/`: the analysis notebooks.

## Data availability
This repository does not include imaging data, segmentations, or any patient-level data.
